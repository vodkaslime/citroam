## 当前产品方案摘要（2026-09-04）

citroam 只有两个一级视图：画布和总览。Agent 是画布上的原生操作层，不是第三个页面、侧栏或另一份任务系统。用户在画布中打开对话入口，说清一件眼前的事，Agent 将它可靠地转换成现有 Card 操作；画布始终留在背景中，结果直接出现在原位置。

```text
打开对话 → 说清一件事 → 看见真实结果 → 继续生活
```

- 对话入口属于画布工具层，`⌘ J / Ctrl J` 在当前画布上打开并聚焦；关闭或切换总览只收起操作层，不改变页面和内容。
- 普通捕获、拖动、编辑、搜索、总览、完成、撤销与本地备份继续走本地链路，不因 Agent 不可用而降级。
- Agent 支持创建、查找 / 打开、改标题、备注或优先级、改日期 / 时段、移到随手页、完成 / 恢复，以及明确集合的批量动作。
- 唯一目标的可撤销动作直接执行并提供“查看 / 撤销”；批量动作先预览确认，删除与覆盖沿用安全确认。
- DeepSeek Harness 只负责模型运行时、工具注册和结构化意图；模型只能调用 `citroam_apply` 提出意图，本地 policy 与既有 Workspace action 决定目标、坐标、提交、Undo 和最终结果。
- 对话不主动问候、推荐、规划、复盘、提醒、催促或评价；没有请求时安静等待。
- 普通捕获与对话拥有独立 draft；收起对话后保留当前会话中的最近消息、候选、待确认和执行中状态，应用重启后不恢复，也不写入 citroam Workspace 或备份。
- 启动、浏览画布和普通本地操作不启动 Harness、不初始化模型、不联网。只有用户提交对话请求时，Tauri 才按需启动或复用 Harness sidecar，并使用设置中的 Keychain API Key（首次运行也兼容环境变量回退）调用真实 DeepSeek provider。

完整的行为契约、Harness 接入、工具边界、状态机、动效、焦点与隐私边界见[产品需求：画布原生 Agent](./product-requirements.md#画布原生-agent)和[产品设计：画布原生 Agent](./product-design.md#画布原生-agent)。画布内对话入口与 Tauri sidecar 桥已接入工程；真实 Harness 构建、密钥配置与窗口验收仍属于发布门槛。

## 一页共识

citroam 是一块本地优先、按天翻页的生活与工作待办画布，不是一套任务管理方法。

> 想到就放下，需要时找得到，做完便过去。

```text
写下一句话 → 放在这一页 → 随手维护 → 完成
```

- Card 同时容纳想法与临时待办；创建只需要一句话。
- 日期天然是一页，不创建日期对象，也不在页内嵌套日期卡片。
- 日期页只有“随时、上午、下午、晚上”四个柔性时段；随手页容纳尚未决定日期的内容。
- Card 可以自由摆放、拖入时段吸附，也可以合法停在时段或日期画布的视觉边界之外。
- 画布、总览与画布内 Agent 共享同一份 Workspace；画布负责维护空间现场，总览、搜索和“看全本页”负责看全与找回，Agent 负责把一句话变成既有操作。
- 日期文字按上下文减法：同年省略年份，跨年时明确显示年份；相对日期与星期各只出现一次。
- 用户手动翻页或切换一级视图时，先提交合法草稿，再结束不属于新现场的详情与编辑态；重复进入当前页保持现场不变。
- 空白页保持安静，捕获栏就是唯一的下一步提示。
- 系统不自动排序、续期、搬运、提醒、评价或解释普通空间位置。
- Agent 原生可达，但只在用户发送明确请求后行动；不引入项目层级、Now、情境匹配或复杂任务状态。
- 启动、翻页和普通画布维护不经过 Agent；只有明确提交对话请求才启动 Harness 并联网。
- 应用设置是统一模态浮层，不是第三个一级视图；外观、Agent 模型 / Harness 路径与本地数据导入 / 导出集中管理。API Key 只存系统 Keychain，保存设置会让下一次请求使用新配置。
- Agent 与拖动、平移等本地操作并发时，所有提交都以最新 Workspace 为准；不能用旧手势或旧响应覆盖用户刚完成的修改，无法安全合并时整体 no-op。普通捕获、手势、Agent 与卸载前的防抖视口写入共用串行保存队列，较新的本地状态不能绕过队列写入。
- 时间、优先级和备注都是可选信息，不能阻挡创建。

## 人本产品原则

citroam 不试图成为用户的教练、裁判或管理者。即使接入 Agent，它也只做好四件事：

1. **接住**：一句话就能留下想法或临时任务。
2. **摆放**：用户按自己的直觉决定日期、时段和位置。
3. **找回**：画布、总览和搜索保证内容不会因自由摆放而丢失。
4. **完成**：完成后安静离场，不评分，不庆功，也不制造新的心理债务。

技术应退到体验背后：核心闭环本地、离线、无需账号即可完整使用；用户内容可以导出，持久修改有撤销或备份恢复路径。任何新能力都不能要求用户理解新的系统概念，不能擅自替用户思考、安排或解释生活。

## 画布原生 Agent

Agent 是画布中的一等操作能力，但不是第三个一级视图、独立页面或第三份内容：

```text
进入对话 → 说一句 → 看见结果 → 继续生活
```

- 普通输入加 Enter 仍然直接创建 Card，不经过 Agent。
- 点击画布工具栏“对话”或使用 `⌘ J / Ctrl J` 打开原生对话层并聚焦输入；点击画布空白、再次按快捷键或切换总览即可收起。
- 明确的单张可撤销操作直接执行；批量操作先预览，删除等破坏性操作必须确认。
- DeepSeek Harness 的 agent loop 只产生结构化操作意图；本地规则负责解析目标、校验后果、修改 Workspace 与生成 Undo。
- 新建、移动、完成和定位继续复用画布既有行为，不建设第二套 Agent 数据模型。
- 对话草稿、最近消息、候选、确认与执行状态在收起或切换总览后保留；执行中的请求不会只因用户看了画布而取消。
- Tauri 只把当前请求所需的最小 Card 摘要送入 Harness；用户未提交请求时不联网，离线核心功能保持完整。
- Agent 不主动推荐、催促、评分、规划生活或重新排列画布。

当前工程已经具备 Harness bridge、`citroam_apply` 工具、结构化意图、本地 policy、目标消歧、单张直达、批量预览、确认、Undo、短记录窗口与失败 no-op，并已接入画布内原生对话层。真实 Harness 构建、密钥配置、焦点边界、完整视觉与真实 Tauri 窗口验收仍是发布门槛，不能在完成前描述为正式可用。

## 四个核心概念

| 词 | 含义 |
| --- | --- |
| Canvas | 当前打开的自由工作空间。 |
| Card | 一句话、一个念头或一项待办。 |
| 日期页 / 随手页 | 天然存在的页面，不需要创建或管理。 |
| Area | 随手页中按需画出并命名的视觉范围，不是 Card 容器。 |

用户只需要决定“放在今天，还是先放在随手页”，不需要先学习任务管理术语。

## 两个一级视图，同一份内容

| 视图 | 作用 | 不做什么 |
| --- | --- | --- |
| 画布 | 捕获、自由摆放、维护空间现场。 | 不自动排序、分组或解释普通位置。 |
| 总览 | 以稳定列表展示未完成与已完成 Card，并定位回画布。 | 不保存第二份顺序，不建设收件箱、Today、统计或批量排程。 |
| 画布内 Agent | 用自然语言创建、查找和维护同一批 Card；始终叠在当前画布上。 | 不建立第三页面或聊天档案，不主动规划、提醒、推荐或评价。 |

总览不是新的主链路。它只提供一个确定答案：每张未删除的 Card 都可以被看见和找回。

## 当前工程基线

当前工程已经具备：

- 日期翻页、今天直达、任意日期选择与随手页。
- 四个柔性时段、自由拖动、时段预览与释放吸附。
- 总览、搜索、定位、“看全本页”、完成、恢复与撤销。
- 画布与总览只挂载当前一级视图；Agent 面板按需挂载，收起后不保留可交互 DOM；切换时结束无关编辑现场，并把对话的易失会话状态保留在视图树之外。
- 总览先呈现 64 行，再在用户接近末尾时自动续载下一批；“再显示 N 张”同时保留为可见、可聚焦的手动入口。未完成总览的日期页与随手页按实际数量比例进入首批，顶部数量始终显示完整数据，而不是当前已渲染行数。
- 总览在 Workspace 尚未加载或读取失败时保持真实状态：显示“正在打开本地内容”或可重试的错误，不把暂时为空误报为“没有未完成的卡片”；只有加载成功后才渲染空状态。
- 空随手页没有 Card 或 Area 时，“看全本页”明确禁用；底层仍是安静的 no-op，不跳视口、不保存，也不制造撤销记录。
- Inspector、Card 就地标题编辑、快速语法与中文输入法保护。
- 搜索输入会同步暴露当前键盘高亮结果，视觉焦点与辅助技术感知保持一致。
- 日期导航会在今天 / 明天 / 昨天显示相对称呼，在普通日期显示星期，但不会在同一个标题里重复星期。
- 应用在前台跨过午夜，或用户重新回到应用时，会刷新相对日期和“今天”入口；当前页面与 Card 保持原位，不自动翻页、不保存。
- 捕获栏在今天 / 明天 / 昨天使用相对称呼，翻到更远日期时直接写出月日或年份，不再用“放进周六”模糊目标。
- 本地持久化、保存失败重试、旧数据迁移与本地备份。
- 页面视口记忆、单一手势会话、临时层焦点与撤销作用域保护。
- 随手页的新 Card、新 Area，以及从日期页移入的 Card 都按当前可见 viewport 与 zoom 落在眼前；Card 先复用空槽，全部占用后才回绕叠放。Area 允许轻微错位，但不会与剩余 Area 完全同坐标。
- 日期页新建 Card 也优先复用目标页时段在可见安全区域内的空槽；若当前页的目标时段已经完全离开视野，只做足以露出新 Card 的最小视口移动。首次从远处平移的随手页进入日期页时，先使用安全的日期场景视口，不把随手页的远处现场带入新日期页；之后仍恢复该日期页自己的会话视口。快速语法捕获到非当前日期页时保持当前现场不动，之后翻入曾经平移过的目标页仍能看到刚捕获的 Card；从总览捕获也保持总览现场，返回画布后再露出 Card；Inspector 跨日移动遵守同一规则。
- 新建 Area 首次聚焦名称时选中默认“新区域”，用户可以直接输入替换；以后重新打开已有 Area 时不再自动全选，即使用户有意保留了这个名称。
- Area 空白平移、Area 移动与 Area 缩放共用 4 CSS px 意图阈值；阈值内的指针抖动不改变几何、不保存，也不制造撤销，实际手势结束后的合成点击不会误开详情。
- Card 拖动使用同一意图阈值；鼠标在阈值内保留普通 click，只有越过阈值后才启用 pointer capture 与原生行为抑制；一旦越过阈值，即使回到原点也不会误开详情，没有净位移时不保存。
- Space + 左键或中键平移也使用 4 CSS px 意图阈值；轻微抖动不移动视口、不保存，真正平移后不会挪动对象或误开详情。
- 普通点击或触控轻点画布空白会提交合法草稿并收起 Card / Area 详情或 Card 就地编辑，焦点回到原对象；不要求用户专门寻找关闭按钮。形成平移时则只移动视口，不触发收口。
- 日期选择器持续标记当前正在查看的日期页；键盘焦点移到其他日期后，当前页仍能一眼辨认。随手页没有日期当前态，不与随手页选中状态竞争。
- 离开画布切换到总览时先关闭日期选择器并清理其临时状态；返回画布不会意外复现旧浮层，也不抢走新视图入口的焦点。
- 本地内容重新打开成功后直接回到捕获栏；若仍无法读取，焦点回到重新打开按钮，不落到页面根节点。
- 加减按钮围绕当前视野中心缩放，不再让用户正在看的内容向左上角漂移。
- `⌘ / Ctrl + 滚轮` 围绕指针缩放；已经处于目标视口时，重复“看全本页”不会闪出一次虚假的保存状态。
- 定位另一张 Card 前先提交当前合法草稿；再次点击已经选中的时段保持幂等，不移动 Card、不保存，也不增加撤销。
- 修改具体开始时间时保留仍晚于它的结束时间；只有原结束时间不再合法时才安静清除，不要求用户重复填写。
- 画布 Card 与总览行的完成圆圈统一使用“完成”悬停提示，不增加常驻文字。
- `Juicy Utility` 视觉语言、短动效、深色主题和减少动态效果支持；状态文字切换时使用 160ms 的轻量过渡，“已存到本机”确认约 1.4 秒后再用 220ms 安静淡出，加载、保存和错误仍持续可见。捕获提交、快速 token、时段选择、浮层关闭、前日书签、撤销、临时选择项、错误恢复、Area 移动 / 缩放把手、删除 / 确认动作与总览标题入口已经具备完整的短 hover / pressed 反馈。所有触感只使用颜色、阴影与轻微位移或缩放，不增加 toast、入口、行装饰或常驻说明；入场动画不占用后续交互位移，无对应界面的旧样式及时删除。`prefers-reduced-motion` 覆盖规则固定放在所有组件动画规则之后，确保页面翻页、画布内 Agent 面板、Card 和反馈动画都能一致降级。
- 日期页面入口使用明确的 navigation landmark；Web favicon 直接复用原生 citroam SVG 标记，不建设第二套品牌资产。
- 全局键盘焦点统一使用明暗主题中都达到 3:1 的 `--focus`，并在所有组件级 outline 重置之后生效；Card 与 Area 的移动手势越过阈值后，实际指针表面统一显示 grabbing。日期复合按钮把当前日期作为可访问描述，删除与导入确认把已有后果文案关联到对话框，不增加可见说明。
- Agent 已复用现有 Workspace action 接入创建、搜索、打开、改名、备注、排期、移到随手页、完成、恢复与删除；普通捕获草稿保持隔离，单张动作提供“查看 / 撤销”，批量动作先确认且只产生一次 Undo，列表查询返回少量可直接打开的事实候选，对话只保留最近 8 条消息并自动滚到最新结果，错误、迟到响应或预览目标状态变化保持 Workspace 原样。画布内面板、Harness bridge、会话保留、焦点边界与并发现场保护已进入工程；真实窗口验收仍待完成。

截至 2026-09-03，416 项自动化测试全部通过，覆盖原生对话入口、Agent core、跨视图会话、并发现场保护、总览、搜索、手势、快速语法、保存与视觉状态。所有搜索、总览与 Agent 候选的“查看”入口统一分流：未完成 Card 回到所属画布并打开详情，已完成 Card 进入“总览 / 已完成”，不打开不可见的画布详情。此前已验证的 `买牛奶#今天`、`买牛奶！高`、Card 元数据语义强调、保存反馈、快速 token、手势仲裁、确认与错误恢复等行为继续作为回归基线；真实 Tauri 窗口验收仍需在有显示权限的环境中完成。

## 取舍规则

新增能力必须同时通过以下判断：

1. 不让“写下一句话”多一个必经步骤。
2. 不要求用户先学习任务管理方法。
3. 不替用户安排生活，也不把普通空间位置解释成硬信息。
4. 不整理时依然可以记录、找到、修改和完成。
5. 派生视图不能制造新的必填字段、持久顺序或维护成本。
6. 对核心链路没有明显帮助时，默认不加入。
7. 核心闭环不能依赖账号、网络或外部服务。
8. 不能用通知、评分、连胜、恐惧或亏欠感制造回访。
9. 能由明确、确定的本地逻辑完成时，不调用 Agent；只有用户主动发起的对话请求可以使用模型推断。
10. Agent 的结果必须可见、可预览或可撤销，不能直接绕过本地规则修改 Workspace。
