## 文档状态

本规格同时记录当前产品基线与发布门槛。需求写进本文不等于工程已经交付：

- “当前基线”表示产品模型和交互方向已经确定。
- “发布门槛”表示属于当前版本，但还需要实现或验收。
- “明确不做”表示主动控制范围，不作为默认路线图。

本文中 Agent 的当前定义以 2026-09-04 的“画布原生 Harness”决策和 AGENT-01 至 AGENT-20 为准；此前关于独立对话页面、临时对话纸片或本地正则替身的记录已被取代，不构成当前需求。

当前发布目标是桌面 Tauri。触控适配可以继续建设，但只有完整手势通过真机验收后才可以对外宣称可用。

本轮设计决策（2026-09-04）：Agent 是画布上的原生操作层，不是第三个一级视图、独立页面或另一份任务系统。`⌘ J / Ctrl J` 在当前画布上打开并聚焦对话输入；画布保持可见，结果直接落回原位置。画布与总览仍是唯一的一级视图，共享同一份 Workspace。

本轮需求落地把 Agent 定义为“人本的原生操作空间”，而不是追逐 AI 热点的展示层：它只减少明确维护的点击成本，不替用户理解生活，也不要求用户学习新工作流。普通捕获和对话输入彼此独立；成功必须产生可见的既有 Card 结果，失败必须保持 Workspace 原样。具体界面与状态要求见[产品设计：画布原生 Agent](./product-design.md#画布原生-agent)，可执行验收集中在 AGENT-01 至 AGENT-20。

本轮实现边界（2026-09-04）：生产 Agent 通过 Tauri 管理的 DeepSeek Harness sidecar 运行真实模型。Harness 以 SDK JSON-RPC 启动，按需创建稳定 session，加载 citroam 专用 `citroam_apply` 工具。模型只能返回结构化 `AgentIntent`，不能写文件、生成坐标或直接修改 Workspace；本地 reducer、policy、并发保护与 Undo 仍拥有最终执行权。`localAgentModel` 仅作为 Vitest 测试替身，不是生产退化路径。Harness 未构建、密钥缺失、网络失败或响应无效时，Agent 请求失败且 Workspace 保持原样，普通本地能力继续离线可用。

本轮产品决策补充（2026-09-03）：Agent 只“代替一次点击”，不“代替用户思考”。它面向眼前的日常维护，而不是聊天、规划或陪伴：用户说清一个意图，系统直接完成一个可验证动作；只有目标不唯一或必要信息缺失时，才提出一个最小问题。创建、移动、改名、备注、优先级、完成、恢复、查找和打开都必须回到现有 Card / Workspace 行为，结果可见且可撤销；一次操作结束后不自动追问、不推荐下一步、不把对话延长成新的任务流程。该决策由 AGENT-01、AGENT-04 至 AGENT-07、AGENT-09、AGENT-11、AGENT-13 至 AGENT-19 共同验收，不新增独立的 Agent 需求编号。

本轮产品设计落档（2026-09-04）：Agent 的完整用户链路固定为“打开对话 → 说清一件事 → 看见真实结果 → 继续生活”。对话层覆盖当前画布，不增加一级页面；收起或切换总览不会清空对话草稿、最近 8 条消息、候选、待确认或执行中状态。单张明确动作直接执行，批量动作只增加一次预览确认；删除或覆盖仍走现有安全确认。Harness 只负责模型运行与工具调用，不生成坐标、不改变画布结构、不引入项目层级、提醒、自动排程或推荐。歧义、无效、超时、断网或请求期间现场变化都保持 no-op，并明确说明画布没有变化。短会话只存在当前应用内存；Harness 自身的运行日志与 session 数据必须放在独立运行目录，不得写入 citroam Workspace 或备份。默认目录为 App 进程专属临时目录，退出时清理；设置 `CITROAM_HARNESS_HOME` 后改用用户指定目录且不由 citroam 删除。界面、状态机、动效与隐私边界见[产品设计：画布原生 Agent](./product-design.md#画布原生-agent)。

本轮产品结论（2026-09-04）：Agent 的“人味”只来自安静、自然、克制和可靠，不来自人格表演。它作为画布原生操作层存在，但只有用户发送明确请求时才行动；没有请求时不问候、不推荐、不规划、不催促，也不评价。任何 Agent 结果都必须写回现有 Workspace，并使用同一份 Card、视口、动画、焦点与 Undo 协议。

## 产品定义

citroam 是一块本地优先、按天翻页的生活与工作待办画布。

用户不需要先建立清单、项目或优先级。想到什么就写一句话：今天要做的留在今天，没有日期的念头放进随手页。之后可以拖动、补充、换一天或完成。

```text
写下一句话 → 放在这一页 → 随手维护 → 完成
```

一句话定位：

> 一块让人轻松放下、安排和完成事情的本地待办画布。

它尤其适合不愿先建立严格顺序、喜欢边做边整理的人，但不使用人格标签定义用户，也不要求用户适应某一种规划方法。

## 产品承诺

> 想到就放下，需要时找得到，做完便过去。

这个承诺落实为十条不可破坏的约束：

1. 标题之外没有创建必填项。
2. 日期天然存在，不需要用户创建、管理或清理日期对象。
3. 不整理也能记录、找到、修改和完成 Card。
4. 系统不自动搬运、续期、排程、催促或评价事项。
5. Agent 是画布原生操作层，但不能成为创建、编辑、找回或完成 Card 的必经路径。
6. 自由摆放不能以“卡片可能看不见”为代价；任何未完成 Card 都必须可以被看全、搜索和可靠定位。
7. 直接创建、编辑、排期、完成、搜索、总览与备份不依赖账号、网络或外部服务；Agent 不可用时这些能力保持不变。
8. 用户拥有内容与空间的最终解释权；系统只对明确动作给出确定、可理解的结果。
9. 用户造成的持久修改必须可以撤销，或通过明确确认与本地备份恢复，不能让轻微误触造成不可理解的损失。
10. 模型不能直接修改 Workspace；它只能提出结构化操作意图，由本地规则校验、执行并生成可见回执。

“对话”入口始终可见。应用启动、浏览画布和普通本地维护不启动 Harness、不初始化模型、不发起网络请求；只有用户提交明确对话请求时，Tauri 才启动或复用 Harness sidecar，并把最小必要上下文交给 DeepSeek provider。外部调用失败时普通功能不受影响。

## 人本产品宪章

citroam 只服务于正在生活和工作的人，不以“更智能”为独立价值，也不把用户改造成更服从工具的人。产品只承担四项工作：

- **立即放下**：想法出现时，用一句话接住，不插入分类表单。
- **按天生活**：今天、其他日期与随手页天然存在，不要求维护容器。
- **自由维护**：Card 可以摆放、修改、换一天，也可以暂时不整理。
- **安心完成**：完成是一项普通状态变化，不触发评分、连胜、庆功或亏欠感。

产品不替用户做决定。日期、时段和位置表达的是用户当下的选择，不是系统对重要性、意图或性格的推断。只有用户直接操作，或主动向 Agent 发出明确请求时，Card 才会被移动、排期、完成或删除。

核心体验必须在离线状态完整成立。网络、账号、云端服务与第三方接口不得成为直接创建、编辑、找回、完成或备份的前提。原生对话需要真实 Harness 与 DeepSeek provider；Harness 不可用时仅该次对话请求失败，画布、总览、搜索与普通捕获仍完整可用。

## 当前产品状态

当前数量与 Agent 形态说明（2026-09-04）：工程完整回归为 438 项；Agent 已收敛为画布内覆盖面板，并通过 Tauri 调用真实 DeepSeek Harness；应用设置已提供模型、Keychain 和 Harness 路径配置。下方较早的 416 项、421 项与 436 项统计和“一级视图”措辞属于历史快照，不能覆盖当前基线。

当前版本已经从“任务列表加一个画布视图”收敛为一块按天翻页的生活画布。下面这些决策是本规格的当前基线，后续功能不能绕开它们另建一套任务模型：

- 日期页是由本地日期即时派生的页面，不是用户创建、移动或清理的对象。
- 日期页内部只有“随时、上午、下午、晚上”四个柔性时间围栏；它们提供语义，不提供排班表或 24 小时轴。
- Card 可以停在围栏之间、围栏外，甚至暂时离开当前可视范围；用户的空间记忆优先于系统的整齐。
- 拖入围栏时先给出高亮和吸附预览，释放时才建立时段关联并吸附；拖出围栏则保留日期、恢复为“随时”。
- 画布与总览是同一份 Workspace 的两种一级投影；对话是覆盖在画布上的原生操作层。画布负责空间维护，总览负责看全和找回，对话负责把明确语言转换成既有动作；三者都不创建第二份内容或状态。
- 空白日期页不显示解释型空状态文案。捕获栏就是唯一的下一步提示，避免给用户增加阅读负担。
- 时段、随手页与总览也不使用品牌化小句反复解释界面；名称、状态、数量和操作本身承担信息表达。
- 日期页 Card 只显示页内需要的时间精度，不重复当前日期；总览与搜索保留完整日期上下文。
- 日期标题、总览与搜索在同一年内省略年份；目标日期跨出当前年份时明确显示年份。今天 / 明天 / 昨天使用相对称呼，普通日期以星期作为 eyebrow，主标题不再重复星期；轻量文案不能制造日期歧义或信息回声。
- 应用在前台跨过本地午夜，或从后台重新获得焦点 / 可见性时，刷新“今天 / 昨天”等相对日期和“回到今天”入口；当前 pageKey、Card、视口与草稿保持不变，也不写 Workspace 或 Undo。
- 搜索、“看全本页”和定位是自由画布的安全出口；它们只恢复可见性，不自动搬运、重排或收拢 Card。
- 空随手页没有 Card 或 Area 时没有需要恢复的全貌；此时“看全本页”明确禁用，底层保持当前视口不动，不保存 Workspace，也不增加 Undo。
- 翻页时保留每个页面在当前会话中的视口位置；这是界面状态，不创建日期数据，也不因翻页额外保存 Workspace。
- 从已经平移很远的随手页首次进入某个日期页时，不继承随手页的远处视口；按当前舞台尺寸使用安全的日期场景视口，让固定日期场景立即可见。之后进入该日期页时恢复它自己的会话视口。这个切换只改变界面现场，不写 Workspace 或 Undo。首次进入随手页时先判断已有 Card / Area 是否完整可见；已经在当前视野内则保留原现场，只有确实超出视野才 fit。
- 所有在随手页“刚发生”的空间动作都以该页当前 visible viewport 与 zoom 为准：新建 Card、新建 Area、从日期页移入 Card 都必须落在眼前。可见槽位有限，填满后允许回绕叠放，但不能继续把新内容推向屏幕外。
- 日期页捕获同样以目标页的 visible viewport、zoom 与舞台尺寸为准：先复用目标时段中完整可见的开放槽位；目标时段完全离开视野时，只移动足以露出新 Card 的最小距离。快速语法投向非当前日期页时不打断当前输入，也不移动当前页；用户之后翻到目标页时才以该页会话视口最小幅度露出刚捕获的 Card。用户在总览捕获到当前日期页时同样留在总览，主动返回画布后才露出 Card。Inspector 把未完成 Card 移到另一日期页时遵守同一规则，不能让 Card 跟随过去却落在屏幕外。
- 用户手动翻页表示离开旧页面，不能把旧 Card Inspector 带到新页；切页前先提交有效文字草稿，再关闭旧详情。Card 在 Inspector 中改日期属于移动当前 Card，页面跟随 Card，详情继续保持打开。
- 页面离场以目标 `pageKey` 是否变化为准，而不是以用户是否点了导航控件为准。重复选择当前日期或当前随手页是幂等动作：不提交草稿、不关闭 Inspector、不重置视口，也不播放换页动画；若日期选择器已打开，只关闭该临时层。
- 画布与总览切换会提交并结束不属于目标视图的 Card Inspector、Area Inspector 与 Card 就地标题编辑；打开、收起对话层不会改变一级视图，对话草稿、最近消息、候选和待确认状态保留在当前应用会话。离开随手页时，Area 改名必须先提交，不能依赖浏览器是否先触发 blur。
- 总览在“未完成 / 已完成”之间切换也属于上下文边界：先提交并关闭旧 Card Inspector，再显示新的索引状态；焦点留在用户刚操作的状态按钮。
- 总览必须区分 Workspace 加载中、读取失败和加载成功的空状态：未加载或失败时不能显示“没有未完成的卡片”，而要显示真实状态；读取失败提供“重新打开”，只有成功读取后才渲染空列表。
- 离开画布切换到总览时显式关闭日期选择器并清理临时状态；返回画布不会复现旧日期浮层，也不会抢走总览入口留下的焦点。
- 搜索进入已完成结果时，先清除旧 Card、Area 与就地编辑上下文，再进入总览已完成状态；不能让上一张未完成 Card 的详情与搜索目标同时出现。
- 从总览或搜索定位 Card 时，必须同时更新 Workspace / 会话 viewport 与屏幕实际使用的可见 transform；持久状态改变但界面没有移动不算定位成功。
- 撤销当前 Inspector Card 的日期变更时，页面与 Inspector 应跟随 Card 回到恢复后的页面；如果恢复状态中已没有该 Card，则关闭 Inspector。
- 已完成 Card 的日期修改与撤销只更新数据，不改变用户当前或稍后返回时看到的画布页；只有仍在画布可见的未完成 Card 才携带页面与 Inspector 一起移动。
- 从 Card 切换到 Area、完成 Card 或开始拖动前，先显式提交当前合法草稿，再基于最新 Workspace 执行目标动作；不能依赖 blur 的触发顺序。
- 从总览或搜索定位另一张 Card 也属于直接动作：先提交并结束旧 Card、Area 与就地标题现场，再从最新 Workspace 计算目标页面和视口，不能用定位前的旧快照覆盖草稿。
- Area 名称按 Enter 是显式保存，不是离开编辑：提交后输入继续保持焦点；只有用户主动点击或 Tab 到别处时才失焦，并且提交逻辑不得把焦点抢回。
- Area 移动、Area 缩放与 Area 空白平移使用同一 4 CSS px 意图阈值。阈值以内的鼠标抖动不是一次变形：几何保持不变，不保存 Workspace，也不产生 Undo。
- 当前页的缩放数字与控制按钮必须使用该页的会话视口，不能读取其他页面或全局默认比例。
- 缩放不能让用户正在观察的位置漂走：加减按钮以可见舞台中心为锚点，`⌘ / Ctrl + 滚轮` 以指针位置为锚点，双指缩放以两指中点为锚点。
- 已经处于目标视口时，重复“看全本页”或其他无净变化的视口命令不触发保存状态；已经选中的时段再次点击也不改变 Card、层级或 Undo。
- 常驻纯图标控件必须兼顾键盘可访问名称与鼠标可发现性；悬停提示只补充动作含义，不在界面中增加一排永久文字。
- 关键次级文字需要达到稳定可读的字号下限；极小字号只允许用于不承担操作与状态判断的纯辅助信息。
- `760 × 560` 是桌面最小窗口基线，压缩时先隐藏装饰与重复反馈，不能隐藏搜索、日期导航、捕获或错误恢复路径。
- 异页捕获提示、撤销和保存失败恢复共用捕获栏上方的一条反馈轨道。它们可以同时存在，但不能重叠，也不能与日期导航争用顶部中央位置。
- 最小桌面窗口可以隐藏日期导航的装饰分隔线，但不能隐藏按需出现的“今天”返回动作。
- 非破坏性浮层因用户点击另一个可聚焦控件而关闭时，焦点留在新控件；这也包括日期选择器打开时点击随手页、前一天、后一天或今天。只有 Escape、点击普通空白，或选择浮层内随后会消失的日期选项时，才回原日期触发器。
- 快速语法候选随捕获现场出现和离开：`#`、`!`、`！` 可以直接紧接中文标题，不要求人为插入分隔空格；点击捕获栏外即收起，重新聚焦仍含有效片段的输入框时恢复，不丢失输入。候选展开时按 Escape 只结束候选层，不清空输入，也不关闭已经打开的 Inspector。
- 全局快捷键不能制造第二个操作现场：删除或备份导入确认存在时，`⌘ K` / `Ctrl K` 只阻止浏览器默认动作，不关闭确认框，也不打开搜索；搜索已经打开时重复快捷键只维持当前搜索，不清空查询。
- 从捕获输入打开搜索时先临时收起快速候选；关闭搜索并回到仍含有效片段的捕获输入后，候选按输入自然恢复，不额外记忆一份候选状态。
- Workspace 撤销不能穿透临时操作层：搜索、日期选择器、备份菜单、删除确认或备份导入确认存在时，非文本控件上不带 Shift 的 `⌘ Z` / `Ctrl Z` 只阻止默认动作，不修改背后的 Workspace；输入框与文本域继续使用原生文字撤销。当前没有 redo，`⌘ Shift Z` / `Ctrl Shift Z` 保持安静且不消费撤销历史。
- Inspector 关闭时不能把焦点送回隐藏视图：原入口仍连接且可见才返回，否则优先回当前画布中的同一张 Card，最后回捕获栏。
- 总览行没有离场动画，完成或恢复导致行消失时立即恢复焦点；画布 Card 仍在 260ms 完成动效后恢复，且不覆盖用户主动选择的新焦点。
- 备份导出和无效导入都要回到本地备份入口；合法导入继续进入应用内确认层，不增加新的中间步骤。
- 搜索和备份入口暴露真实展开状态；备份入口名称描述下一步是打开还是关闭。选择导入时应用菜单先收起，取消系统文件选择后回到入口。
- 搜索结果使用键盘浏览时，输入框通过 `aria-controls` 与 `aria-activedescendant` 指向当前可见高亮项；视觉选择、Enter 打开的目标与辅助技术感知必须是同一张 Card。
- 本产品只增加用户主动调用的对话 Agent，不增加自动排程、自动提醒或复杂项目层级。Agent 不能改变普通捕获链路，也不能在没有请求时“帮助整理”。

这意味着当前阶段的重点是可靠性和可理解性，而不是继续增加字段或视图：让用户能放心丢下、随手移动、随时找回，并在完成后安静地结束一次行动。

## 用户要完成的事

### 立即放下

想法或临时任务出现时，输入一句话并按 Enter，立刻回到原来的生活或工作。

### 看今天，但不被日历管理

打开产品时直接看见今天这一页。需要时像翻书一样看前一天、后一天或任意日期，不进入传统月历、周历或 24 小时时间轴。

### 暂时不决定

尚未决定什么时候做的内容可以合法存在于随手页，没有“未归类”“积压”或红色提醒。

### 按自己的空间直觉维护

同一天内的 Card 可以自由摆放。时段只是一组柔软背景，不把事项排成严格列表。

### 看全与找回

总览提供同一批 Card 的稳定列表投影。搜索和定位可以先切到 Card 所属页面，再找到原位置；“看全本页”必须把当前页散落在固定日期边界之外的未完成 Card 一并纳入视野。

### 用一句话完成一次维护

不想打开详情或逐张操作时，用户可以进入原生“对话”视图，说“把报销放到明天下午”“这个做完了”或“把今天没做完的移到周五”。Agent 只执行这次请求，不主动延伸为计划、建议或提醒。

## 核心概念

| 概念 | 用户含义 | 是否持久化为独立对象 |
| --- | --- | --- |
| Card | 一句话、一个念头或一项待办。 | 是 |
| 日期页 | 某一天的画布页面。 | 否，由 `YYYY-MM-DD` 即时派生 |
| 随手页 | 没有日期的自由画布。 | 否，固定键 `loose` |
| Area | 随手页中可选的命名范围。 | 是 |
| 总览 | 全部 Card 的规整列表投影。 | 否 |
| 对话 Agent | 解释自然语言并调用既有 Card 操作的原生一级工作空间。 | 否；会话只在应用内存，动作写入既有 Workspace |

日期页不是可以移动、缩放、收起、删除或手动创建的 Card。它是当前画布本身的日期语义，不在页面内部再嵌套日期卡片。空日期页也是有效页面，浏览它不会产生持久数据。

## 信息结构

```text
citroam
├── 画布
│   ├── 随手页
│   └── 日期页（任意本地日期）
├── 总览
│   ├── 未完成
│   │   ├── 日期页 Card
│   │   └── 随手页 Card
│   └── 已完成
└── 画布工具层
    └── 对话面板（按需覆盖当前画布）
```

没有收件箱、项目树、Today 清单、计划页或统计页。应用设置是唯一的统一配置浮层，用于外观、Agent 连接参数和本地数据导入 / 导出，不承载任务工作流。

“对话”是画布工具层的一等操作能力，不是第三个一级视图或第三份内容。它与画布、总览共享同一 Workspace；打开或收起只改变当前操作层，不复制 Card。

### 画布原生 Agent

本节全部属于发布门槛。当前工程已经实现 Harness bridge 与首条行为链路，但只有 AGENT-01 至 AGENT-20 的自动化、完整视觉、焦点边界、真实模型配置、全量回归与真实 Tauri 窗口验收全部通过后，才可描述为正式可用。

设计目标是让 Agent 原生融入画布，同时把每次操作保持得足够短：用户打开对话层，说一句明确的话，看见真实结果，然后继续在画布或总览中生活。普通捕获、编辑、搜索、总览、完成、撤销和本地备份不经过 Agent；Agent 不主动规划、推荐、提醒或评价，也不能绕过本地 policy、确认和 Undo。

#### 设计落地摘要：最短、最舒服的链路

这里的“舒服”不是让 Agent 更像一个会表演人格的聊天机器人，而是让一次明确维护尽量少打扰、少确认、结果可见并且随时可撤销。产品承诺固定为：

```text
打开对话 → 说一句 → 看见结果 → 继续生活
```

- 对话是画布工具层，不是第三个一级视图、独立页面或永久聊天档案；它覆盖当前画布并可随时收起，底部普通捕获栏仍保持可见。
- 普通捕获始终直接创建 Card；对话使用独立草稿，切换视图或失败都不能吞掉正在输入的标题与快速 token。
- 唯一目标的单张创建、移动、改名、排期、完成或恢复直接执行，并给出一句回执以及“查看 / 撤销”；批量动作只增加一次预览确认，删除和覆盖本地内容沿用默认取消的安全确认。
- Agent 只把自然语言翻译为既有 Workspace action。模型不能生成坐标、直接写入 Workspace 或建立第二套任务模型；本地 policy 负责目标消歧、确认等级、原子提交和 Undo。
- 处理中只反映真实解析或执行，不表演思考；失败、超时、断网、无效 schema 或上下文变化统一保持 no-op，并明确告诉用户“画布没有变化”。
- Agent 入口始终可达，但只在用户发送明确请求后行动；不主动问候、推荐、规划、复盘、催促或评价，可用性来自可靠和尊重沉默，而不是人格表演。
- 生产模型通过 Tauri 管理的 DeepSeek Harness sidecar 运行；只发送完成当前请求所需的最小 Card 摘要。Harness 不可用时，创建、编辑、拖动、搜索、总览、完成、撤销与本地备份仍完整离线可用。

| --- | --- | --- |
| AGENT-01 | 对话是画布原生操作层。 | 画布工具入口固定可达；点击“对话”或按 `⌘ J / Ctrl J` 在当前画布上打开并聚焦输入。它不是第三个一级页面，不复制 Card，也不提供“关闭即清空会话”的生命周期。 |
| AGENT-02 | 普通捕获永远绕过 Agent。 | 默认输入加 Enter 继续确定性创建 Card；Harness 断网、未构建或处理失败时，普通捕获与其他本地功能完全可用。 |
| AGENT-03 | 对话与捕获草稿互不覆盖。 | 进入对话时保留尚未提交的普通捕获草稿；切换回画布或总览后原文字与 token 原样恢复。对话输入使用独立的会话草稿，不能把一条 Card 草稿误解释成指令。 |
| AGENT-04 | 对话使用眼前的明确上下文。 | 可以引用当前 pageKey、进入对话前或最近明确选中的一张 Card、当前总览状态及当前会话中仍有效的目标；存在目标 Card 时显示“正在处理：标题”。“这个”“它”等代词只在上下文唯一时解析，目标切换、删除或应用会话结束后不沿用失效引用。 |
| AGENT-05 | 支持有限且完整的 Card 操作。 | 支持创建、改标题、备注或优先级、改日期或时段、移到随手页、完成、恢复、搜索、打开，以及用户明确指定集合的批量移动或完成；也支持按日期查询未完成或已完成 Card，查询只读、不产生 Workspace 写入。查询回执必须与状态一致：未完成使用“还有 N 张未完成”，已完成使用“有 N 张已完成”，空结果分别说“没有未完成的 Card”或“没有已完成的 Card”。自然日期遵循本地日历语义：`下周一`指下一周的周一，不因当前星期早晚多跳一周。口语时间允许自然空格（例如“明天下午 3 点”），解析后仍必须是合法的 `HH:mm`，且与声明的上午 / 下午 / 晚上时段一致；结束时间必须同时有开始时间并晚于开始时间。校验失败保持 no-op，不猜测或部分执行。不支持自动拆项目、生成计划、解释空间关系或调用产品模型之外的状态。 |
| AGENT-06 | 单张明确操作直接完成。 | 对唯一目标执行创建、修改、移动、完成或恢复后，返回一句短回执和“查看 / 撤销”；不再要求一次无意义确认。 |
| AGENT-07 | 批量操作先预览。 | 一次请求影响多张 Card 时，先显示动作、数量和可辨认的目标摘要；当前页仍可见的开放 Card 以临时半透明虚线轮廓标出，轮廓不可交互、不写入 Workspace，取消或确认后清理；用户确认后作为一个原子事务执行，并只生成一条 Workspace Undo。 |
| AGENT-08 | 破坏性操作必须明确确认。 | 删除或覆盖本地内容时复用现有安全确认层，默认焦点为取消；模型不能把自然语言中的模糊表达直接当成删除授权。 |
| AGENT-09 | 歧义只追问一个最小问题。 | 找到多个同名目标或缺少必要日期时，不猜测、不修改 Workspace，只展示少量可辨认候选或询问一个直接问题。 |
| AGENT-10 | 模型不直接写数据。 | 模型输出结构化 `AgentIntent`；本地解析器解析 Card 身份，本地 policy 校验动作与确认等级，既有 Workspace action 执行最终修改。无法通过 schema 或 policy 的输出保持 no-op。 |
| AGENT-11 | Agent 复用既有空间语义。 | Agent 新建 Card 使用当前可见空槽；移动日期或时段使用既有自动放置和最小露出；未完成 Card 的查看回到所属画布并打开详情，已完成 Card 的查看进入“总览 / 已完成”而不打开不可见画布详情；完成、定位与撤销沿用现有动画、焦点和层级规则。除用户明确要求打开 / 查看或点击回执“查看”外，成功动作留在 Agent 面板，不自动跳走。不得另写坐标或建立第二套 repository。 |
| AGENT-12 | 上下文披露保持最小且本地边界清楚。 | 启动、浏览和普通本地操作不启动 Harness、不发起网络请求；用户提交对话请求时才按需启动或复用 Harness，并仅提供当前请求、明确引用对象和解析所需的 Card 摘要，不上传完整坐标、Area、备份或永久对话历史。生产 provider 使用 DeepSeek Harness 运行配置；缺失配置时请求失败且 Workspace 不变。 |
| AGENT-13 | Agent 不主动说话。 | 对话入口始终可见并不等于主动介入；没有用户请求时不弹出问候、推荐、复盘、提醒或“今天还有什么”，也不根据未完成数量、行为历史或空间位置主动评价用户。 |
| AGENT-14 | 会话保持轻且短暂。 | 当前应用会话内只保留最近 8 条消息（每条用户输入或 Agent 回执各算一条），新消息进入时淘汰最早消息并把最新内容自动滚入消息区；Agent 处理中仍可编辑下一句，但同一时刻只允许一个请求执行，进入候选或确认态后需先完成或取消当前动作。草稿、候选、确认和短上下文在一级视图切换或组件重新挂载后保留，但应用重启后不恢复，也不写入 Workspace、备份或永久模型上下文；`prefers-reduced-motion` 下自动滚动改为即时滚动。 |
| AGENT-15 | 失败必须诚实且无副作用。 | 超时、断网、模型错误、schema 错误、执行冲突或请求期间现场变化时，显示直接说明（现场变化时为“当前现场已经变化，这次没有执行。画布没有变化。”）及重试 / 修改输入路径；失败不能留下半张 Card、部分批量结果或已消费的 Undo。 |
| AGENT-16 | 对话可以完整键盘操作。 | 打开面板后聚焦对话输入；Enter 发送，Escape 先取消候选或确认等最近一层，再回到输入，再次按下收起面板。流式回应和动作回执使用 polite live region，不反复抢读。 |
| AGENT-17 | 批量确认只作用于仍然有效的预览目标。 | 预览后任一目标 Card 的完成状态已经改变时，确认整体保持 no-op；不部分移动、不部分完成、不消费 Undo，并明确告诉用户画布没有变化。 |
| AGENT-18 | 并发操作不覆盖最新现场。 | Agent 请求、Card / Area 拖动或画布平移同时发生时，提交必须基于执行或释放时的最新 Workspace，只合并本次动作负责的字段；Agent 修改的标题、备注、优先级、完成状态等不能被旧手势覆盖，视口更新也不能写回旧 Card / Area。若目标身份、版本或上下文已失效且无法安全合并，整体保持 no-op，不部分执行、不消费 Undo，并明确告诉用户画布没有变化。 |
| AGENT-19 | 收起或切换时保留对话现场。 | 用户收起面板、翻页或切换到总览时，先提交合法 draft 并结束不属于目标现场的 Card / Area / 就地编辑，再只保留面板的草稿、最近 8 条消息、候选、待确认与执行中状态。收起不能取消合法的执行中请求，也不能抢回用户刚切换后的焦点。 |
| AGENT-20 | 生产 Agent 必须连接真实 Harness。 | Tauri 仅在用户发送请求时启动或复用 DeepSeek Harness SDK sidecar，并按 `initialize` → `session/prompt` → 事件收集 → `shutdown` 的 JSON-RPC 生命周期工作。Harness patch 只加载 `citroam_apply`，禁用 shell、文件、网络、子 Agent、计划和其他通用工具；`localAgentModel` 只能出现在测试注入中。模型、Harness 根目录和 API Key 优先读取应用设置：模型与根目录是应用配置文件中的非敏感字段，Key 只来自系统 Keychain；没有已保存配置时兼容 `CITROAM_DEEPSEEK_MODEL`、`CITROAM_HARNESS_ROOT` 与 `DEEPSEEK_API_KEY` 环境变量。缺少 Harness 构建、Key 或有效 provider 时请求失败且 Workspace no-op；默认使用 App 进程专属临时运行目录并在退出时清理，设置 `CITROAM_HARNESS_HOME` 后使用用户指定目录且不由 citroam 删除；两者都不写入 Workspace 或备份。当前 deepseek-harness checkout 的 host 构建仍有既有 missing export 错误，发布前需由 Harness 项目修复或提供可运行构建产物。 |

### Card

| 编号 | 需求 | 验收 |
| --- | --- | --- |
| CARD-01 | 想法与任务使用同一种 Card。 | 没有类型选择与“未分类”警告。 |
| CARD-02 | Card 可以自由拖动。 | 拖动期间完全跟手；释放只保存一次最终坐标并生成一次 Undo。 |
| CARD-03 | 日期页拖动可以改变柔性时段。 | Card 中心进入对应背景带后，释放写入“随时 / 上午 / 下午 / 晚上”并吸附到该围栏的可放置范围；落在围栏间隙或围栏外时保留日期并放宽为“随时”，手动拖动不受页面边界限制。 |
| CARD-04 | 具体时间受到保护。 | 在兼容时段内移动保留具体时间；进入其他时段或离开所有围栏时才移除具体时刻。 |
| CARD-05 | Card 可以直接维护。 | 支持标题、备注、日期、时段、具体时刻和可选优先级。 |
| CARD-06 | 改日期等于 Card 自己换页。 | Inspector 改日期后 Card 原子移动到目标日期页，并按目标页会话 viewport 与 zoom 选择目标时段中的可见槽位；若该时段完全离开视野，则只移动足以露出 Card 的最小距离。清除日期后进入随手页，并使用目标随手页的 visible viewport 与 zoom 重新落在可见槽位。未完成 Card 跟随到目标画布、保持详情打开且 Card 本身可见。从“移到随手页”按钮触发且按钮消失时，焦点回到仍存在的日期字段。从总览修改未完成 Card 时同样进入目标画布；已完成 Card 继续留在总览，因为它不会显示在画布上。该行为不同于用户手动浏览其他页面。 |
| CARD-07 | Card 可以完成与恢复。 | 画布或总览可完成；已完成从总览恢复后保留原页面与坐标。恢复不会擅自切到“未完成”或画布。总览行没有离场动画，当前行消失且焦点仍在完成 / 恢复按钮上时立即回到捕获栏；画布 Card 则等待 260ms 离场动画结束。两种情况都不得覆盖用户已经主动选择的新焦点。 |
| CARD-08 | Card 可以删除。 | 删除前明确确认；删除与完成不混用。已删除 Card 不再接受完成 / 恢复切换，只有撤销或本地备份恢复可以找回。 |
| CARD-09 | 拖动结果可以预见。 | 拖动期间经过时段围栏时高亮目标、显示轻量语义反馈与吸附预览；进入间隙或外围时明确回到“随时”。预览不写 Workspace。 |
| CARD-10 | 定位结果始终可见。 | 从总览或搜索定位时，先提交并结束旧 Card / Area / 就地标题草稿，再从最新 Workspace 切页，以同一目标值更新当前屏幕 transform、会话 viewport 与 Workspace viewport，最后临时提升目标 Card 的视觉层级并播放一次强调；平移过画布或存在重叠 Card 时，目标都必须实际进入视野且可操作，旧草稿不能被定位前快照覆盖。 |
| CARD-11 | 文字编辑一次提交。 | Inspector 标题/备注与 Card 就地标题使用本地 draft，失焦、明确确认或离开应用时提交一次；日期、时段与优先级仍可即时提交，避免每个字符产生一次持久化。就地标题按 Enter 保存、按 Escape 取消，两种键盘收尾都回到重新出现的 Card；普通 blur 保留用户已经移到的焦点。备注占位文案只写 `补充备注...`，不解释备注可以为空。 |
| CARD-12 | Card 元数据服从页面上下文。 | 日期页已经表达日期，因此 Card 的 `anytime` 不显示时间标签，上午、下午、晚上只显示时段，具体时刻只显示 `HH:mm` 或 `HH:mm-HH:mm`；总览与搜索显示日期上下文。同年日期省略年份，跨年日期显示年份。时间可以使用强调色帮助扫描，但优先级和备注不能因为恰好排在元数据第一项就继承时间强调。 |
| CARD-13 | 直接动作不能覆盖文字草稿。 | 从 Card 切换到 Area、完成 Card 或开始拖动前，先提交当前合法标题与备注 draft，再从最新 Workspace 计算选择、状态与位置更新。最终结果必须同时保留最新文字和目标动作，不依赖输入框先 blur。 |
| CARD-14 | 按需字段接住下一步。 | 点击“添加具体时间”后直接聚焦新出现的开始时间输入；不能让触发按钮消失后把焦点留在页面根节点。Inspector 初次打开仍优先聚焦标题，不被已有具体时间抢走。 |

### 日期页与时间

| 编号 | 需求 | 验收 |
| --- | --- | --- |
| TIME-01 | 日期页是固定画布场景。 | 顶部导航是唯一日期标题；工作区不再嵌套日期 Header、数量标签或日期卡片容器，也不显示移动、缩放、收起、复制、创建或删除页面的控件。 |
| TIME-02 | 页面内部只有四个柔性区域。 | 四块区域使用轻边框、柔和底色和至少 20px 的垂直间距清楚区分“随时、上午、下午、晚上”，不建设 24 小时轴；围栏之间和外围仍是可放置的自由画布。 |
| TIME-03 | 时段不产生严格顺序。 | 区域内 Card 不按时间、优先级或创建时间自动排列。 |
| TIME-04 | 位置和时间写入保持一致。 | 日期 Card 的 `placement.pageKey` 必须等于 `timeConstraint.date`。 |
| TIME-05 | 日期使用本地语义。 | 使用 `YYYY-MM-DD` 本地日期键，不用 UTC 日期替代用户看到的一天。 |
| TIME-06 | 具体时刻是可选精度。 | 支持 `HH:mm` 开始时间与可选结束时间；修改开始时间时，若原结束时间仍晚于新开始时间则保留，否则清除无效结束时间。不自动提醒或排程，也不要求用户重复填写仍然合法的信息。 |
| TIME-07 | 空日期不累积数据。 | 用户浏览再多日期，Workspace 中也不会出现 page 数组或日期对象。 |
| TIME-08 | 时段标签直接、克制。 | 时段背景只显示图标和“随时 / 上午 / 下午 / 晚上”，不附加“慢慢醒来”一类装饰性说明；语义不只依赖颜色。 |
| TIME-09 | 当前时段保持幂等。 | Card 没有具体时刻时，再次点击已经选中的时段不改时间、坐标、层级或更新时间，不保存，也不增加 Undo；有具体时刻时点击时段仍表示主动降回柔性时段。 |
| TIME-10 | 缩放不牺牲时段识别。 | 日期页缩放时，时段图标与文字使用反向比例保持接近正常屏幕可读度；只调整标签的视觉显示，不改变围栏命中几何、Card 坐标或拖放语义。 |

### 随手页与 Area

| 编号 | 需求 | 验收 |
| --- | --- | --- |
| LOOSE-01 | 无日期内容有稳定归宿。 | `timeConstraint` 为空的 Card 必须使用 `pageKey: "loose"`。 |
| LOOSE-02 | 随手页保持自由画布。 | Card 可以任意摆放，不显示时段、不自动对齐。 |
| LOOSE-03 | 空随手页保持安静。 | 没有 Card 或 Area 时不显示标题、段落或使用说明；背景和捕获栏已经足够表达可以开始。 |
| AREA-01 | Area 只在随手页出现。 | 用户可以创建、改名、移动、缩放或删除 Area；日期页不显示创建 Area 的入口，v3 导入也拒绝把 Area 放到日期页。 |
| AREA-02 | Area 是视觉范围，不是容器。 | Card 放在 Area 范围内只表达用户看得懂的空间关系，不建立项目成员关系；移动或缩放 Area 不自动搬运 Card。 |
| AREA-03 | Area 不成为项目系统。 | 不拥有进度、状态、排序、自动行为或独立列表。 |
| AREA-04 | 删除 Area 不删除 Card。 | Card 内容、页面和坐标保留。 |
| AREA-05 | Area 改名保持轻量。 | 输入过程中使用本地 draft；失焦或 Enter 一次提交，Escape 放弃本次草稿，不按字符写入持久层。Enter 保存后名称输入继续保持焦点；点击或 Tab 到别处产生的普通失焦只提交，不抢走新焦点。从随手页离开、切换到总览或直接开始移动 / 缩放前，先提交有效改名；手势从最新 Workspace 保存位置和尺寸，不依赖 blur 的触发顺序。 |
| AREA-06 | Area Inspector 不打断路过操作。 | 新建 Area 或明确点击 / 轻点 Area 时打开 Inspector 并聚焦名称；只有新建后的首次聚焦完整选中默认“新区域”，直接输入即可替换。重新打开已有 Area 时不自动全选，即使它仍叫“新区域”。键盘只聚焦移动 / 缩放控件时不自动打开详情，实际移动或缩放后的合成 click 也不打开详情。关闭、Escape、鼠标点击或触控轻点画布空白后回到对应 Area 的移动把手；删除后回到捕获栏。 |
| AREA-07 | 新建 Area 出现在眼前。 | 新建位置按随手页当前屏幕实际使用的 visible viewport 与 zoom 计算，并在可见世界范围内留出稳定内边距；不能退回 Workspace 的旧 viewport，也不能引用其他日期页的会话视口。连续新建可以轻微错位，删除较早 Area 后也先复用未占用的偏移，不能与剩余 Area 完全同坐标；每个新 Area 至少保留可直接抓取和命名的可见部分。 |
| AREA-08 | Area 只响应明确的变形意图。 | 移动和缩放把手共用横纵绝对位移和超过 4 CSS px 的阈值。阈值以内释放时保持原位置与尺寸，不保存、不增加 Undo；越过阈值后即使最终回到原几何，也消费本次合成 click，但几何没有净变化时仍不保存。 |

| OVERVIEW-04 | 总览不复制数据。 | 打开详情、完成、恢复均操作同一 Card。完成或恢复导致当前筛选中的行消失时，保留当前总览状态，不用自动导航掩盖状态变化。 |
| OVERVIEW-05 | 定位先切页面。 | 定位 Card 时先读取 Placement 的 `pageKey`，再切画布并移动视口。 |
| OVERVIEW-06 | 总览是一眼可读的索引。 | Header 只保留“总览”和带真实数量的“未完成 N / 已完成 N”切换，不显示 kicker 或介绍段落；空状态只用“没有未完成的卡片”或“还没有完成的卡片”一行说明。 |
| OVERVIEW-07 | 状态切换结束旧详情。 | 从“未完成”切到“已完成”或反向切换时，先提交并关闭当前 Card Inspector，再显示目标列表；不能让旧 Card 详情悬在已经换掉的索引上，焦点保留在刚操作的状态按钮。 |
| OVERVIEW-08 | 总览空状态只在数据可信时出现。 | Workspace 加载中显示“正在打开本地内容”，读取失败显示“没能打开本地内容”与“重新打开”；两种状态都不能误报为空列表。只有读取成功后，才根据真实数量显示“没有未完成的卡片”或“还没有完成的卡片”。重试失败不覆盖已有数据，重试成功后进入正常总览。 |
| OVERVIEW-09 | 一级视图只保留一个活动界面树。 | 画布与总览一次只挂载当前一级视图；对话层只在画布上按需挂载，收起后不保留不可见可交互 DOM。切换前继续遵守草稿提交、Inspector 关闭与焦点规则，对话的易失会话状态提升到视图外保留。不得用 `hidden` 同时保留多套完整 DOM。 |
| OVERVIEW-10 | 大总览渐进呈现但保持完整可达。 | 首批最多渲染 64 行；未完成状态同时存在日期页与随手页时，按各自真实数量比例分配首批且每组至少显示一行。滚动接近批次末尾时自动增加 64 行，同时保留“再显示 N 张”按钮供键盘、辅助技术或不支持观察器的环境继续加载。顶部未完成 / 已完成数量始终来自完整数据，切换状态或重新进入总览时重置到首批。 |
| SEARCH-01 | 搜索标题与备注。 | 未完成结果定位所属页；完成结果先关闭旧 Card / Area / 就地编辑上下文，再进入总览已完成状态，不能保留无关的旧 Inspector。 |
| SEARCH-02 | 搜索结果可以辨认。 | 每个结果至少显示标题，以及存在时的日期、时段和完成状态；同名 Card 不依赖备注内容才能区分。 |
| SEARCH-03 | 键盘浏览不中断。 | 上下键改变当前结果时自动保持该行可见；搜索输入通过 `aria-controls` 关联结果列表，并以 `aria-activedescendant` 指向当前高亮项，确保视觉选择、Enter 目标与辅助技术感知一致。关闭搜索后焦点返回打开搜索的控件或捕获入口。 |
| SEARCH-04 | 搜索不改变内容。 | 定位只切页、移动视口并强调目标；不会改 Card 的日期、时段、坐标或持久层级。 |
| SEARCH-05 | 快捷键提示服从桌面平台。 | macOS 显示 `⌘ K`，Windows 与 Linux 显示 `Ctrl K`；两类修饰键都能实际打开搜索。 |
| SEARCH-06 | 搜索快捷键是幂等入口。 | 搜索已经打开并输入查询后，再按 `⌘ K` / `Ctrl K` 不关闭搜索、不清空查询、不重置当前结果；焦点仍留在同一个搜索对话框内。 |

### 可靠性

| 编号 | 需求 | 验收 |
| --- | --- | --- |
| SAFE-01 | 核心能力离线可用。 | Card、页面归属、坐标、Area 和视口均保存在本机。 |
| SAFE-02 | 保存与读取状态可信。 | 显示加载、保存、成功和失败；失败不以空 Workspace 覆盖原数据。总览在 Workspace 加载中或读取失败时保持对应的真实状态，不渲染空列表。可见保存状态使用 polite、atomic live region 播报变化；每次状态文字切换以约 160ms 淡入并上移 2px，“已存到本机”约 1.4 秒后以 220ms 淡出，加载、保存与错误持续可见。外层 live region 与固定布局不重建，不另建通知中心或 toast。保存失败与撤销、异页捕获提示共用捕获栏上方的反馈轨道，不遮住日期导航；保存重试后临时按钮消失时，焦点回到捕获输入。本地内容读取重试成功后同样回到捕获输入；若仍失败，焦点回到重新出现的“重新打开”按钮。 |
| SAFE-03 | 高频误操作可撤销。 | 至少覆盖创建、移动、改日期、完成、删除 Area。页面前后翻页本身不写入数据，也不产生 Undo。若当前 Inspector Card 的日期变更被撤销，页面跟随 Card 回到恢复后的日期页或随手页并保持 Inspector；恢复状态中不再有该 Card 时关闭详情。 |
| SAFE-04 | 手势生命周期统一。 | pointermove 只更新临时视觉，不写持久状态；释放时只有存在净变化才提交一次。Card、Area、Space + 左键与中键平移都使用 4 CSS px 意图阈值；阈值内抖动、越过阈值后回到原几何，以及达到缩放上下限后的继续输入都不保存、不增加 Undo。越过阈值的序列即使回到原点也消费合成 click。Escape、pointercancel、失焦和卸载取消并还原。 |
| SAFE-05 | 旧数据自动迁移。 | v1 notes Task 与 v2 画布完整迁入 v3，标题、备注、状态、日期、时段、优先级不丢失。 |
| SAFE-06 | 临时层关闭后回到合理位置。 | 日期选择器、搜索、确认框、Inspector 和画布内对话层支持 Escape；Escape 在对话层中先取消候选或确认，再回到对话输入，第二次收起对话层。离开画布时先关闭日期选择器并清理临时状态，返回画布不能复现旧浮层。普通左键点击或触控轻点画布空白会先提交合法 Card / Area / 就地标题草稿，再收起当前详情或编辑态并回到原对象；若 pointer 目标本身可聚焦，则保留它获得的新焦点。模态确认打开时焦点不能进入背后的画布或对话输入。 |
| SAFE-07 | 本地内容可以备份。 | 低频入口支持导出完整 Workspace JSON 与确认后导入；导入使用应用内确认层，明确说明当前画布会被替换且导入后仍可撤销。选择导入后，应用菜单先关闭再打开系统文件选择器；用户取消文件选择时焦点回到备份入口。确认前不修改数据；Escape 取消、Tab 保持在确认层内，结束后焦点回到备份入口。导出完成或无效导入同样回到备份入口；合法导入继续进入确认层。导入失败不覆盖当前内容，导入前保留可恢复副本。入口使用硬盘 / 存储语义图标，不复用品牌标记，并提供“本地备份”可访问名称与悬停提示。它不是云同步，也不进入主链路。 |
| SAFE-08 | 菜单可以只用键盘操作。 | 备份菜单打开后聚焦第一个菜单项；上下键循环，Escape 关闭并回到触发按钮；点击菜单外关闭时不抢走用户刚刚点击的焦点。入口通过 `aria-expanded` 表达真实状态，并把下一步动作命名为“打开 / 关闭本地备份菜单”。 |
| SAFE-09 | 离开应用前刷新文字草稿。 | `beforeunload`、`pagehide` 和 React 卸载路径都提交最新合法的 Inspector、Card 就地标题和 Area draft；没有草稿变化时不重复保存。任何紧随其后的属性、日期或移动更新也必须基于最新 Workspace 合并。 |
| SAFE-10 | 更名不切断旧本地数据。 | 用户可见品牌统一为 citroam；早期 `notes` bundle identifier、Store 文件名与 localStorage key 在没有完整迁移和回滚方案前继续作为内部兼容标识。内部旧名不得出现在窗口标题、产品文案或导出内容的用户可见品牌中。 |
| SAFE-11 | 页面上下文不能错位。 | 手动翻页、一级视图切换、搜索进入已完成结果及离开随手页后，不得继续展示不属于当前现场的 Card / Area Inspector 或就地编辑。先提交有效草稿，再切换上下文并关闭旧层；Card 自己改日期、撤销该日期变更、搜索定位和总览定位只携带被明确操作的目标 Card。 |
| SAFE-12 | 被移除的操作对象不带走焦点。 | 最后一次撤销使撤销按钮消失、Card 完成离场、总览完成 / 恢复使当前行消失，或 Area 被删除时，若焦点仍在即将消失的控件上，则回到捕获栏；关闭 Area Inspector 回到该 Area。总览行没有离场动画时立即恢复，画布 Card 等待离场动画；若期间用户已主动移动焦点，系统不得抢回。 |
| SAFE-13 | Inspector 不返回隐藏视图。 | 关闭 Card Inspector 时，只有原打开入口仍连接且不在隐藏视图内才返回该入口。否则优先返回当前画布中同一张 Card 的可见打开控件，仍不存在时回捕获栏；从总览改日期进入画布后尤其不能把焦点送回隐藏的总览行。 |
| SAFE-14 | 任一时刻只有一个模态焦点域。 | 删除确认或备份导入确认打开时，全局搜索与 Agent 快捷键不得打开或替换确认现场；确认框、搜索、对话内部确认与背后的快速候选不能同时成为活动焦点域。从候选进入搜索或对话时先隐藏候选，临时层关闭并回到仍含有效片段的捕获输入后再恢复。 |
| SAFE-15 | Workspace 撤销服从当前操作层。 | 焦点在输入框、文本域或选择控件内时保留控件自身的撤销行为；焦点在搜索、对话、日期选择器、备份菜单、删除确认或备份导入确认的非文本控件上时，不带 Shift 的 `⌘ Z` / `Ctrl Z` 不穿透到未确认的背后 Workspace。Agent 成功回执中的“撤销”明确撤销刚完成的原子 action；关闭临时层后，全局组合继续撤销 Workspace。当前没有 redo，`⌘ Shift Z` / `Ctrl Shift Z` 不执行 Workspace 操作，也不得消费 undo 历史。 |
| SAFE-16 | 持久化提交保持串行且按最新现场执行。 | 普通捕获、文字编辑、Card / Area 手势、Agent action 与卸载前的防抖视口冲刷共用同一条串行保存队列；每次提交都从当时最新的 Workspace 生成快照，新的本地提交不能绕过队列，旧的进行中写入也不能在较新写入之后落地覆盖内容或视口。组件卸载只把待写入视口追加到队列，不直接调用 repository；队列完成后才结束本次冲刷。 |
| SAFE-17 | 千卡规模仍保持直接操作感。 | 使用 1,000 张代表性 Card 的固定数据集，以 React Profiler 累计提交时长验收：捕获 `<40ms`、翻页 `<40ms`、Card 拖放 `<40ms`、搜索 `<30ms`、总览首屏 `<80ms`。`pnpm test:performance` 是发布检查；调优不得通过跳过持久化、Undo、焦点、完整总数或隐藏内容来换取通过。 |

### 输入设备

桌面 Tauri 是当前发布基线。窄窗口适配不等于触控支持；移动端只有在以下手势通过后才可以宣称可用。

| 编号 | 需求 | 验收 |
| --- | --- | --- |
| INPUT-01 | 鼠标画布直接可靠。 | 普通左键拖 Card；Space + 左键或中键平移；滚轮平移，修饰键滚轮围绕指针缩放。Space + 左键可以从页面空白、Card、Area 空白或 Area 把手开始，且优先于对象拖动；两种鼠标平移都在超过 4 CSS px 后才启动，阈值内不移动视口、不保存。Card 或 Area 移动越过阈值后，实际位于指针下的 Card 标题表面或 Area 移动把手显示 grabbing；释放后恢复原 cursor。真正平移释放后的合成 click 不打开 Card / Area 详情；普通左键点击空白只结束当前编辑现场。点击、双击编辑与拖动阈值不互相误触。 |
| INPUT-02 | 触控手势有明确分工。 | 单指拖空白平移，单指拖 Card 移动，双指缩放；第一根手指若从 Card 开始，第二根手指落在 Card 或空白画布时都升级为同一场双指缩放，Card 恢复原位置。未越过平移阈值的画布空白轻点提交并收起当前 Card / Area Inspector 或 Card 就地编辑，焦点回到原对象。`touch-action: none` 不能造成既不能滚动也不能平移的死区。 |
| INPUT-03 | 键盘可以完成非空间任务。 | 捕获、搜索、对话、打开、编辑、完成、恢复、关闭浮层与撤销均可只用键盘完成；空间移动不作为第一版键盘必需能力。 |
| INPUT-04 | 画布手势不产生跳变。 | 第二个触点出现时，单指平移或 Card 拖动都升级为同一场双指缩放；缩放围绕双指中点，限制在 0.5–1.8；对象拖动被取消且不写入 Card 坐标，抬起时一次提交 viewport，取消时恢复手势前视口。 |
| INPUT-05 | 临时修饰状态不跨越失焦。 | 窗口失焦时释放 Space + 左键平移状态并取消进行中的空间手势；返回窗口后，未再次按下 Space 的普通左键拖动不能继续平移画布。 |
| INPUT-06 | 轻点与拖动不会串台。 | Card、Area 空白、移动把手与缩放把手共用 4 CSS px 意图阈值。Area 空白单指越过阈值后只平移视口；没有越过阈值的明确轻点直接选择 Area，不依赖浏览器补发 click。鼠标 Card 在阈值内保留普通 click，不提前 `preventDefault` 或抢 pointer capture；只有越过阈值后才启用拖动捕获并消费同一序列的 click。Card 与把手在阈值内抖动不修改几何；一旦越过阈值，即使回到原点也只结束手势，不打开详情。Card 触控拖动中出现第二指时，当前对象手势立即让位给 pinch，Card 不提交中间位置。普通左键由 Card、Area 把手与其他控件处理，按住 Space 时页面空白、Card、Area 空白与 Area 把手统一让位给画布平移。合成 click 只抑制当前事件序列，不能吞掉下一次正常点击。 | 

### 桌面界面可用性

| 编号 | 需求 | 验收 |
| --- | --- | --- |
| UI-01 | 现有控件可被鼠标发现并感知操作。 | 主题、前后日期、缩放、画布与总览的完成圆圈，以及响应式布局中隐藏文字后的搜索、“看全本页”和“新建区域”具有简短 `title`；文字与 `aria-label` 使用同一个动作含义。“对话”优先保留一级导航文字标签，不使用难猜的 AI 图标。主题和备份等状态型动作同步描述将要发生的结果；搜索与备份入口暴露真实 `aria-expanded`，一级视图使用 `aria-pressed` 或等价当前态。捕获提交、快速 token、时段选择、具体时间、搜索、日期选择器关闭、前日书签、撤销、“重新打开”和“重试”等动作，日期选择、快速候选、搜索结果、Agent 候选与备份菜单等临时选择项，以及 Area 移动 / 缩放把手、删除 / 确认动作与总览标题入口，都具有 90–140ms 的完整 hover / pressed 反馈。Area 把手显现与按压不突跳；删除入口悬停轻抬、按下轻压；确认按钮轻抬并收紧阴影，但主操作与危险操作的底色保持不变；总览标题只做文字显色和极轻按压，不增加行背景、边框或 Card 装饰。快速 token、前日书签与撤销的入场动效不能覆盖交互 transform。关闭浮层和含义已经由所在控件文字说明的把手不机械增加重复提示；已经移出界面的旧按钮样式不得继续残留。 |
| UI-02 | 关键次级信息可稳定阅读。 | 默认比例下，日期主标签至少 12px；Inspector 字段与具体时间、时段按钮、快速语法说明、总览元数据与数量、搜索结果上下文、日期选择和拖放反馈至少 10px。低于 10px 的文字不得是完成操作或理解状态的唯一线索。 |
| UI-03 | 桌面最小窗口仍能走完主链路。 | Tauri 最小窗口为 760×560；允许收起品牌文字、保存成功反馈、日期装饰分隔线和捕获语法提示，但画布 / 总览、画布工具层对话、搜索、页面导航、按需出现的“今天”、捕获、缩放、保存失败恢复与必要临时层仍可达，不依赖横向页面滚动。对话面板两侧至少保留 16px 安全间距，主导航与输入固定可达，消息区独立滚动；保存失败、异页提示和撤销同时出现时必须全部可读、可操作且不互相遮挡。 |
| UI-04 | 提示不制造新的视觉噪声。 | 悬停提示只服务常驻且仅靠图标不易理解的控件；已有清楚文字标签的按钮不重复添加解释。可点击感通过短暂的颜色、阴影与 transform 反馈表达，不增加常驻边框、说明或永久展开的工具栏。`prefers-reduced-motion` 覆盖块必须位于所有组件动画规则之后，确保页面翻页、Agent 面板、Card 与反馈动效统一降级。 |
| UI-05 | Area 的键盘焦点可见。 | 键盘焦点进入 Area 内任意操作时，Area 边界和缩放把手复用悬停 / 选中态显现；焦点离开后恢复安静状态，不常驻展示把手。 |
| UI-06 | 画布结构与关键决策可被辅助技术辨认。 | 日期页面入口使用命名 `navigation`，画布操作区使用命名 `region`，紧凑画布控制使用命名 `group`；日期复合按钮以当前日期作为 `aria-describedby`，删除与备份导入确认以已有后果文案作为对话框描述。所有原生控件和程序化聚焦对象的焦点环使用 `--focus`，在明暗主题的 Canvas 与 Surface 上都达到 3:1。语义增强不增加可见容器、标题、说明或工具栏。 |
| UI-07 | 品牌入口使用同一标记。 | 原生应用图标、Web favicon 与界面品牌使用同一 citroam 视觉源；favicon 直接复用现有 SVG，不额外引入第二套图标风格。 |

## Workspace v3 数据模型

```ts
type CanvasPageKey = "loose" | `${number}-${number}-${number}`;

interface TimeConstraint {
  date: string; // YYYY-MM-DD
  period: "anytime" | "morning" | "afternoon" | "evening";
  startTime?: string; // HH:mm
  endTime?: string;   // HH:mm
}

interface CardPlacement {
  cardId: string;
  canvasId: string;
  pageKey: CanvasPageKey;
  x: number;
  y: number;
  zIndex: number;
  areaId: string | null;
  updatedAt: string;
}

interface Area {
  id: string;
  canvasId: string;
  pageKey: "loose";
  title: string;
  x: number;
  y: number;
  width: number;
  height: number;
}

interface Workspace {
  schemaVersion: 3;
  canvas: Canvas;
  cards: Card[];
  placements: CardPlacement[];
  areas: Area[];
}
```

必须满足：

- 有日期 Card：`placement.pageKey === card.timeConstraint.date`。
- 无日期 Card：`placement.pageKey === "loose"`。
- Card 与 Area 每个只属于一页。
- `areaId` 是 v3 兼容字段，不是用户可见的项目成员关系；新交互不因 Card 与 Area 重叠而自动写入归属。
- Workspace 不保存 `pages`、日期页实例或空日期访问历史。
- Workspace 不保存 Agent 对话、模型消息或待执行意图；Agent 会话状态属于易失 UI state。
- 应用设置不属于 Workspace：主题偏好与非敏感 Agent 配置写入 Tauri 应用配置目录，API Key 只写系统 Keychain；Workspace JSON 导入 / 导出不得携带任何设置凭据。
- 页面切换只改变 UI state，不调用 repository.save。

## 旧数据迁移

### v1 notes Task

- 有 due date：变成日期页 Card，精度为 `anytime`。
- 无 due date：进入随手页。
- 保留 ID、标题、备注、优先级、完成状态和时间戳。

### v2 旧画布

- 旧日期容器内 Card：进入对应日期页，保留时间精度，坐标转换为页面内坐标。
- 有时间但未关联容器的 Card：进入其日期对应页面。
- 无时间 Card：进入随手页。
- 旧 Area：进入随手页。
- 旧日期容器迁移后丢弃，不进入 v3。

迁移失败时必须保留原存储并报告读取失败，不能返回假的空画布。

## 明确不做

- 常驻聊天侧栏、浮在捕获栏上方的临时对话纸片、永久聊天时间线或必须经过 Agent 的任务管理流程。
- Agent 主动拆解、推荐、复盘、总结、规划一天或解释用户行为。
- 让模型直接读写 Workspace、绕过本地校验、确认等级或 Undo。
- 自动把昨天未完成 Card 搬到今天。
- 自动排程、自动续期、自动归档或自动重新浮现。
- 红色逾期债务、积分、连胜、生产力评分。
- 项目、目标、子任务、依赖、标签体系或复杂状态机。
- 传统月历、周历、24 小时网格和会议日程管理。
- 页面对象管理、批量创建日期或页面清理。
- Card 连线、框选、批量工具、可调整尺寸或随机颜色。
- 强制防重叠、自动避让、自动收拢或自动对齐 Card。
- 云同步、多人协作、通知与系统提醒。
- 强制登录，以及让账号成为本地内容或核心功能的使用前提。
- 社交动态、排行榜、连续打卡、行为画像或生产力分析。
- 以增长和回访为目的的通知、红点、恐惧文案或奖励循环。
- 未经用户明确打开对话并发送请求，把本地内容发送到 DeepSeek Harness 或其他外部服务。

## 产品体验指标

这些指标约束产品是否仍然轻便，不用于评价用户：

1. **两秒捕获**：输入已经获得焦点时，用户可在两秒内写下一条短 Card 并提交；主链路只有“输入并按 Enter”。
2. **零创建决策**：创建过程中没有标题以外的必填字段，也不弹出分类、日期或优先级表单。
3. **五秒找回**：已知大致内容时，任意未删除 Card 可在五秒内通过当前画布、总览或搜索找到。
4. **离线完整**：断网时仍可创建、编辑、移动、排期、完成、搜索、查看总览、导出和导入本地备份。
5. **改动可恢复**：普通持久修改有撤销路径；破坏性操作明确说明后果，并保留本地备份恢复路径。
6. **长期仍直接**：至少 1,000 张 Card 的本地数据规模下，捕获、翻页和拖放的 React 提交各 `<40ms`，搜索 `<30ms`，总览首屏 `<80ms`；由 `pnpm test:performance` 固定进入发布检查。
7. **无心理债务**：产品不使用逾期红字、未完成总数、连胜、评分或催促通知作为留存手段。
8. **一句话操作**：唯一目标的可撤销 Agent 请求在一次发送后直接完成；批量请求最多增加一次确认，不演化为多步向导。
9. **结果可相信**：每次 Agent 修改都有可见画布结果与回执，失败保持 Workspace 原样；所有批量修改是一个原子事务。
10. **Agent 不绑架主链路**：Harness 未构建、密钥缺失、断网或模型失败时，该次请求 no-op，所有直接操作与离线指标保持不变。

33. 跨过本地午夜或重新回到应用后，相对日期与“今天”入口自动刷新，但页面、Card、视口、Inspector 和草稿不被搬动或关闭，也不产生保存与 Undo；随手页日期选择器不伪造日期当前态；本地内容读取重试成功回捕获栏，失败回重试按钮。

36. 普通左键点击画布空白会提交并收起当前 Card / Area 详情，焦点回到原对象；新 Area 的默认名称已选中，可直接输入替换。Space + 左键与中键的 4px 内抖动不移动视口、不保存。
37. 远日期捕获栏明确写出月日或年份；新 Card 先复用日期页或随手页的空槽，全部占用后才叠放；新 Area 不会与仍存在的 Area 完全同坐标。
38. 日期页平移或窗口收窄后，新建 Card 仍优先落在目标时段的可见安全槽；目标时段完全离开视野时只做足以露出 Card 的最小视口移动，并与创建共用一次 Undo。快速语法投向非当前日期页时不改变当前页，之后进入曾经平移过的目标页仍能看到刚捕获的 Card；总览捕获保持总览现场，返回当前画布后 Card 进入眼前；Inspector 跨日移动也保持 Card、详情和目标页可见。日期页面入口具有 navigation landmark，Web favicon 与原生图标使用同一视觉源。
39. 在断网且未登录任何账号的状态下，创建、编辑、移动、排期、完成、搜索、总览、本地备份导出与导入完整可用；核心链路不调用外部服务。

42. 普通捕获与对话草稿互不覆盖；画布 / 总览切换、Agent 断网、超时或返回无效 schema 都不会改变直接捕获与现有 Workspace。
43. 唯一目标的单张 Agent 操作直接执行并提供“查看 / 撤销”；多目标操作先预览并在确认后原子提交；破坏性操作仍通过安全确认层。
44. “这个”“它”只引用界面中明确显示的当前 Card；多条同名 Card 通过一个最小问题消歧，未确认前保持 no-op。

46. 外部模型只获得请求所需的最小上下文；首次启用前说明数据去向，对话历史不写入 Workspace，应用重启后不恢复。
47. `⌘ J / Ctrl J`、Enter、Escape、Tab、流式回应、回执、预览和错误恢复可以完整键盘操作并被辅助技术理解；760×560 窗口中对话工作空间的主导航、输入、回执和确认始终可达。
